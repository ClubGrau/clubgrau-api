# Canal is born empty

Instagram, TikTok, and Google on the indications screen are prototype labels, the same kind of data as Campanha Cristianinho and Campanha Verão. Canal starts with no origins. A channel is created the same way as a campaign. Startup inserts nothing.

PRD v1.1 and the indications glossary record this. There is no seed function and no `bornKey`. A seed that recognized the three channels by name would recreate them after a correction. A seed that recognized them by a private key would keep a special handle on records the product treats as ordinary origins. Both are rejected with the seed itself.
